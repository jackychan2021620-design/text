## 已有自动检查

本地测试使用临时库，不写入门店经营数据。

- 工作台空库、业务隔离与独立数据目录。
- 选题 → 素材 → 草稿 → 待发布 → 已发布 → 已复盘的真实保存与阶段门槛。
- 待确认占位阻止误入待发布，未实际发布不能录入效果。
- 版本冲突保护，过期编辑不能覆盖更新。
- 累计反馈取最新采集日快照，未知与零值区分，指标数值和日期验证。
- 资料授权、AI 白名单上下文、素材只发送描述不发送文件。
- 素材复制去重、关联保护、CSV 公式注入保护。
- 数据库备份恢复、完整 ZIP 跨目录恢复、路径遍历和哈希损坏拒绝。
- 七尺寸图标结构、四入口和三种尺寸、实际编辑保存、长回复与固定输入框。
- 模拟模型发现、SSE 完整 / 不完整 / 认证 / 超时 / 取消、确认发送前不写入、不自动应用模型建议。
- 入口启动、退出、重启、资料保留和每日备份重复运行。

## Windows 构建检查

GitHub 构建运行上述测试，打包后使用隔离目录实际启动 `ZaowuContentStudio.exe --smoke-test`，确认退出成功并建立数据库，才生成安装程序。

安装界面使用 Inno Setup 官方消息键并提供主要步骤中文说明。安装过程与图标视觉仍需真人检查。程序未配置商业签名证书。

## 真人需要验证的体验

1. 下载并双击安装包，不安装 Python也可启动。桌面、开始菜单、任务栏图标一致。
2. 首页能找到一个明确的下一步；手动完整推进一条真实内容，保存、关闭、重开保留。
3. 参考案例 → 选题 → 素材的关联正确，无需重复介绍同一产品。
4. 用有效 Key 获取模型并完成流式生成。核查发送文本；取消不写入，生成不自动改业务；检查后应用草稿。
5. 发布记录不对外发送；真实反馈未知可空；不同采集日累计值不重复汇总。
6. 备份完整 ZIP，在另一数据目录恢复，素材可打开；坏备份不影响现有数据。
7. 最小化、最大化、调整尺寸、关闭与托盘；开机启动默认关闭；退出不遗留网络线程。
8. 升级安装保留资料，卸载选择“否”保留；只有选择“是”才删除该工作台资料。

## 0.3.0 图文收藏验收

- 分享文字识别 `xhslink.cn` / `xhslink.com` 和笔记长链接，保留分享参数；拒绝其他域名、凭据 URL 与非笔记页面。
- 固定浏览器脚本仅提取当前笔记的标题、原文、图片列表，不序列化账户状态或 Cookie。
- 图片下载验证 CDN 域名、每次重定向、文件类型与体积；按原顺序解码保存，缺图不标记完整。
- 收藏与本店素材隔离、重开保留、重复更新需确认并保留人工拆解、完整 ZIP 含参考图且跨目录恢复。
- 资料版本1自动备份并迁移到2，旧版备份可恢复到新版。
- 看图请求确实含实际图片像素；请求确认、模型与 Key 分开，数据库审计不保存 Base64 或凭据。
- Windows 打包和安装后均执行真实 Chromium 内核的离线网页提取检查。离线夹具不代表已成功读取用户提供的真实笔记。

开发云环境的 Linux 沙箱阻止 Chromium 创建子沙箱；没有关闭浏览器沙箱来规避。固定提取脚本的本地测试使用 QJSEngine，浏览器完整运行由 Windows 构建验证。

用户提供的微景观短链接目前受云端网络域名策略阻断，未取得真实笔记文案和图片，不能报告图片数量或宣称整篇读取通过。小红书域名配置已保存草稿，需在环境设置保存并发布后再做云端联网验证。也可在安装程序后从本机正常网络打开该链接进行实际验收。
