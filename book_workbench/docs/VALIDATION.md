## 尚未验证：不能标记为Windows正式成品

1. Windows EXE尚未在Windows构建，当前未交付可下载的EXE；提供了启动、设置和打包脚本。Linux不能替代Windows产物验收。
2. Windows实机：中文字体与高DPI、通知授权、托盘关闭／打开／退出、Credential Manager、Run注册表开机启动、外部Tesseract路径、打包后的模型路径均需验证。
3. 真实DeepSeek：需要有效Key、账户余额、模型权限和目标域名访问配置；当前未修改云环境网络或秘密配置。
4. 真实平台截图需逐字段核对，尤其GMV来源、千／万单位与小数点；OCR并不保证正确。销量曲线目前采用人工每日数值录入，不自动从截图曲线推断数字。
5. 未做真实经营的长期运行／大量数据压力测试。备份无加密；生产使用前应测试自己的数据恢复。

## Windows验收操作

1. 全新Windows用户环境安装Python和Tesseract，运行 `scripts/setup-windows.ps1`，确认全部测试实际执行（包含中文OCR）。
2. 运行 `scripts/build-windows.ps1`，确认测试及打包程序启动检查成功；将整个产物目录复制至无Python的Windows机器验证。
3. 录入真实书和至少两个链接、两条视频；保存实际截图并核对。用过去日期触发两种独立提醒；延后其中一条视频，确认另一条和商品任务未变化。
4. 开启后台托盘并关闭主窗，确认通知和重新打开；开启登录启动后注销再登录检查。关闭Windows通知时首页仍应保留待办。
5. 用真实DeepSeek账户执行获取模型、五日复盘与历史分析；核对发送上下文、五类说明、错误响应和安全凭据存储。
6. 备份到外部目录，恢复到另一个数据目录，核对附件和任务；重启检查所有资料不丢失。记录Windows版本、产物哈希、通过项和失败项后再发布。
