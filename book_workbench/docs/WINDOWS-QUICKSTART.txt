图书带货智能选品工作台 V1.1.1

安装版：双击 BookWorkbench-Setup-1.1.1-Windows-x64.exe，按步骤安装。
便携版：先完整解压 ZIP，再双击文件夹内 BookWorkbench.exe。
请勿只复制 EXE 或在压缩包内直接启动。

无需安装 Python 或 Tesseract，运行环境及中英文 OCR 已包含。
目前为未签名试用版本；请确认下载来源为本仓库，并可核对 SHA256SUMS.txt。

第一次使用：
1. 可先建图书及商品，或直接在数据采集新增表单中粘贴商品链接，按提示当场建档。
2. 新增快照 → 选择截图后自动识别 → 在核对窗口查看原图、整页文字及指标建议 → 确认填入 → 勾选已核对 → 保存。
3. 视频投放与复盘 → 新增视频，分别填写发布、广告提交及实际开始日期。
4. 广告数据 → 填写人工核对的实际GMV、后台GMV及其他可见指标。
5. 五日复盘 → 查看建议，填写人工意见后保存。

基础功能离线可用。AI需要在设置中配置自己的DeepSeek Key及模型。
本地资料默认保存在 %LOCALAPPDATA%\BookWorkbench，不放在程序目录。
请定期通过“设置与备份”导出完整ZIP。
卸载保留经营资料和备份；本程序不自动上传数据，不自动发布或投放广告。

关闭到托盘和登录启动均默认关闭，可在设置中开启。
程序完全退出或电脑关机期间不执行提醒，下次启动恢复未完成任务。

V1.1.1修复：粘贴链接当场建档、截图指标核对填入、附件草稿恢复。
旧版“附件路径不安全或文件已丢失”的草稿仍可打开，移除或重新选择附件即可，其他字段保留。
升级请先完全退出旧程序（包括托盘），再运行新版安装包覆盖安装，不必卸载。经营资料目录保持不变。
