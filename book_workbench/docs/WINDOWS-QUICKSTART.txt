图书带货智能选品工作台 V1.1.5

安装版：双击 BookWorkbench-Setup-1.1.5-Windows-x64.exe，按步骤安装。
便携版：先完整解压 ZIP，再双击文件夹内 BookWorkbench.exe。
请勿只复制 EXE 或在压缩包内直接启动。

无需安装 Python 或 Tesseract，运行环境及中英文 OCR 已包含。
目前为未签名试用版本；请确认下载来源为本仓库，并可核对 SHA256SUMS.txt。

第一次使用：
1. 可先建图书及商品，或直接在数据采集新增表单中粘贴商品链接，按提示当场建档。
2. 新增快照 → 选择截图后自动识别 → 在核对窗口查看原图及指标建议 → 确认填入 → 勾选已核对 → 保存。
3. 视频投放与复盘 → 新增视频，分别填写发布、广告提交及实际开始日期。
4. 广告数据 → 填写人工核对的实际GMV、后台GMV及其他可见指标。
5. 五日复盘 → 查看建议，填写人工意见后保存。

基础功能与三档规则推荐离线可用。普通AI问答需要在设置中配置自己的DeepSeek Key及模型。
本地资料默认保存在 %LOCALAPPDATA%\BookWorkbench，不放在程序目录。
请定期通过“设置与备份”导出完整ZIP。
卸载保留经营资料和备份；本程序不自动上传数据，不自动发布或投放广告。

关闭到托盘和登录启动均默认关闭，可在设置中开启。
程序完全退出或电脑关机期间不执行提醒，下次启动恢复未完成任务。

V1.1.4修复：粘贴链接当场建档、截图指标核对填入、附件草稿恢复。
旧版“附件路径不安全或文件已丢失”的草稿仍可打开，移除或重新选择附件即可，其他字段保留。
升级请先完全退出旧程序（包括托盘），再运行新版安装包覆盖安装，不必卸载。经营资料目录保持不变。

V1.1.4：修复中文目录下OCR语言包检查失败。手机截图先解码成PNG，长图分段识别。
销量曲线：截图核对窗口 → 提取销量曲线 → 核对绿色框绘图区及上下刻度 → 预览 → 勾选估算确认 → 填入趋势点。
读图结果不是精确逐日销量；不要用估算点求和替代90天总销量。周期不明的带货人数不会默认勾选。

V1.1.4：已有快照可直接编辑，点击“保存修订版”保存，原记录保留。
销量曲线显示为折线图。使用“从截图提取曲线”或“手动录入销量”；原始识别文本不再显示。
带货人数识别候选会填入；统计周期未确认时可先保存，待核实后再选择“已确认与本次统计周期一致”。

V1.1.4：默认“三档选品推荐”只给档次和短理由，固定规则本地执行，无需Key。需要追问可切换“简短问答”。规则及同类样本门槛可在设置调整，数据不足会说明缺什么，不硬分档。
误录快照：数据采集中心 → 选中错误行 → 删除。记录退出当前计算，可在“回收站”恢复；其他有效记录保留。

V1.1.5：单本书即可三档推荐，不必凑够五本同类商品。默认只显示档次及短理由，门槛可调整。
缺曲线可先归为适合、小量试测；缺核心指标或统计周期不明则先核对。
说明文字可以鼠标选取；表格选中后按Ctrl+C复制，业务表及历史表每页50条。
搜索停顿200ms后刷新；切页保留筛选、分页和滚动位置。表单回车保存，Esc关闭保留草稿。
保存、错误和删除使用轻提示／应用内确认。弹窗和下拉采用180ms过渡，可在设置启用“减少动态效果”，同时尊重Windows动画设置。
抖音账号监测：先点击“立即检查”。只有页面读取成功后才显示作品、挂车商品及点赞。
达到100赞时只提醒一次；读不到书名显示待确认。检查失败保留旧数据及上次成功时间。
默认不自动检查；开启后每30分钟尝试一次，工作台退出、电脑关机或休眠期间不监测。
此公开页面读取器尚未通过三个真实账号的联网验收，不能保证登录限制页面和挂车信息可读，也不能保证全量作品。
