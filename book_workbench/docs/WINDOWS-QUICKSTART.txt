图书带货智能选品工作台 V1.1.7

安装版：双击 BookWorkbench-Setup-1.1.7-Windows-x64.exe，按步骤安装。
便携版：先完整解压 ZIP，再双击文件夹内 BookWorkbench.exe。
请勿只复制 EXE 或在压缩包内直接启动。

无需安装 Python 或 Tesseract，运行环境及中英文 OCR 已包含。
目前为未签名试用版本；请确认下载来源为本仓库，并可核对 SHA256SUMS.txt。

第一次使用：
1. 可先建图书及商品，或直接在数据采集新增表单中粘贴商品链接，按提示当场建档。
2. 新增快照 → 选择截图后自动识别 → 在核对窗口查看原图及指标建议 → 确认填入 → 勾选已核对 → 保存。
3. 视频投放与复盘 → 新增视频，分别填写发布、广告提交及实际开始日期。
4. 广告数据 → 填写人工核对的实际GMV、后台GMV及其他可见指标。
5. 五日复盘 → 查看建议，填写人工意见后保存。

基础功能与三档规则推荐离线可用。普通AI问答需要在设置中配置自己的DeepSeek Key及模型。
本地资料默认保存在 %LOCALAPPDATA%\BookWorkbench，不放在程序目录。
请定期通过“设置与备份”导出完整ZIP。
卸载保留经营资料和备份；本程序不自动上传数据，不自动发布或投放广告。

关闭到托盘和登录启动均默认关闭，可在设置中开启。
程序完全退出或电脑关机期间不执行提醒，下次启动恢复未完成任务。

V1.1.7 当前用法：
抖音监测使用系统Edge／Chrome的专用窗口，避开旧内置浏览器黑屏。第一次需在专用窗口重新登录。
选账号 → 打开抖音并登录 → 回工作台点“加载近期作品”。可单独移动或关闭浏览器窗口，不影响侧边栏。
仅看到旧作品时，使用“加载近期作品”继续加载后续批次。没有赞数的作品不会被整条丢弃，未知日期可单独筛选。
需要补查书名时，选中作品 → 补查书名；公开挂车与文案线索会分别标明，未公开的内容不猜测。
曲线：打开提取窗口后等自动预览；刻度读不清可保存“相对走势0–100”，不代表实际销量。
若要销量刻度，取消相对走势并填写原图上下界；自动识别失败还可沿原图手动描绘。
此包通过画面与点击等离线验收后才提供，三个真实账号仍需登录后核实读取效果。
