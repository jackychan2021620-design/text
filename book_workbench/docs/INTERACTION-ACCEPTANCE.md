# V1.1.7 交互验收

本地158项回归与Windows完整测试已通过，包括真实鼠标跨34次页面点击、等待旧控件销毁、待处理搜索及异常后继续切页。实际EXE和中文路径安装后的程序也执行跨页与浏览器检查。

本次改造针对本地 PySide6 工作台。组件动效时长为180ms；Windows关闭界面动画或工作台开启“减少动态效果”时立即切换，不强制播放动画。操作系统自己的文件选择器由系统控制。

| 场景 | 可验收结果 | 已执行验证 |
| --- | --- | --- |
| 点击按钮 | 按下态先绘制，业务处理随后执行；主次、危险、悬停与焦点状态一致 | Qt按下事件在100ms内可观察到按下态；实际打包程序同样检查 |
| 复制说明与表格 | 说明可鼠标选取；选中表格行后Ctrl+C按制表符复制 | 文字选择属性及实际剪贴板内容测试 |

| 普通保存／提示 | 提示出现在窗口下方，不打开信息确认框，不抢输入焦点 | Qt活动模态窗口及输入焦点保持测试 |
