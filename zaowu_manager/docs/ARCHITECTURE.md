# 架构与数据结构

- `zaowu/schema.py`：所有业务表单字段与类型、业务和阶段枚举。SQLite、验证、表单、文件交换共用定义。
- `zaowu/store.py`：SQLite 初始化 / 版本、事务 CRUD、金额校验、统计、匿名上下文、会话、备份恢复及 Excel / CSV。
- `zaowu/ai.py`：HTTPS 官方域名约束、安全凭据、模型发现、SSE 工作线程。无工具调用、无数据库写权限。
- `zaowu/ui.py`：导航、分标签业务页、表单、经营图表、聊天、设置与托盘。
- `zaowu/__main__.py`：单实例锁、每日备份、历史中断标记、应用生命周期。

SQLite `user_version=1`。当前版本不需要历史迁移；将来修改结构必须递增版本并写增量迁移，不能直接删除旧表。外键开启，WAL 模式，写操作自动提交；程序正常关闭不影响之前的业务保存。应用锁按数据目录隔离。

## 业务表

各表均含 `id INTEGER PRIMARY KEY`、`updated_at TEXT NOT NULL`。

| 表 | 用途 / 关键关联 |
|---|---|
| products | 业务、名称、单价、材料成本、上架、特色 |
| customers | 唯一匿名编号、业务、类型、来源、偏好、推广许可、本地备注 |
| orders | 业务、归属日、产品外键、客户外键、件数 / 组数、人数、新客复购转介绍、来源与渠道、阶段、预计收入、实际收入、三项直接成本、交付日、方式、节日、地点和活动 |
| inventory | 花材入库、领用、损耗、盘盈流水；按名称 + 单位汇总 |
| expenses | 日期、固定费用类型与金额 |
| goals | 指标、目标值、实际值、截止日 |
| campaigns | 假设、人群、预算、花费、成功指标、四级漏斗、结果、状态 |
| tasks | 业务、标题、日期、截止日、待确认等状态、执行结果 |
| contents | 计划发布日期、平台、业务、标题、形式、正文、状态、公开链接和表现 |
| assets | 本地照片文件路径、业务和文字描述；文件以 SHA256 命名避免名称碰撞 |
| competitors | 人工观察及公开来源链接、售价、差异、促销、机会 |
| reviews | 每日 / 每周 / 每月事实、发现和后续追踪 |
| memories | 背景、决策、有效 / 无效方法和逐条 AI 分享授权 |
| followups | 客户外键、沟通日期、阶段、本地沟通内容、下次日期 |

完整字段、中文含义与类型以 `schema.py` 为准；确切建表语句另附 [schema.sql](schema.sql)，已验证可在独立 SQLite 库重建全部表。运行时也可用 `SELECT sql FROM sqlite_master WHERE type='table'` 查看。金额列均为整数分，不使用二进制小数做钱款汇总。文件层用十进制元转换，半入舍入到分。

## 系统表

- `settings(key PRIMARY KEY, value)`：非秘密 UI / API 模型配置；无 API Key。
- `sessions(id, title, created_at)` 和 `messages(id, session_id FK, role, content, status, created_at)`：完整会话与流状态；删除会话级联消息。
- `reports(id, period, start, end, body, UNIQUE(period,start,end))`：上完整周 / 月统计快照；重复维护不重复生成。快照是生成时数据，不跟随后补订单改变；最新结果请查看动态经营分析。
- `audit(id, at, action, table_name, row_id)`：人工业务增改删操作轨迹，不保存敏感内容副本，也不是可自动撤销的版本历史。

## AI 边界与记忆

AIWorker 只接收经确认的数据文本和凭据，不持有 Store 或数据库连接。主线程显式保存聊天；模型不能调用函数或运行命令。业务记忆在独立表持久化，默认不分享；分享后与统计上下文一并传递。模块上下文通过白名单组装，不发送原始客户或订单记录。营销 / 内容 / 复盘资料含人工自由文本，需要在每次发送前核对隐私。历史会话过长时要求用户主动另存结论、开启新会话，不静默截断。

## 首版边界

这不是会计、POS 或多门店协同系统。不提供多商品订单明细、多次收款、退款会计、自动库存配方扣减、平台采集、自动发布、自动投放、图片识别。手动多产品项目可拆为多单，统计订单数会随之变化，应按业务口径统一录入。AI 主动面板提供本地真实统计 / 工作提醒；联网诊断需用户主动确认发送，不后台未经确认上传经营数据。每周 / 月自动报告是本地统计快照，不冒充已生成的 DeepSeek 分析。
