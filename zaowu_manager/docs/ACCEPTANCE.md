# 发布前验收

开发验证与 Windows 发布验证要分开记录。测试中的业务数字仅存入 pytest 临时目录，绝不进入真实用户库。

## 本地自动测试

在 `zaowu_manager` 下执行 `python -m pytest -q`，覆盖：

- 三业务收入与成本、取消 / 未成交排除、来源与下单渠道分别统计。
- 客户首次消费、复购、未关联客户、跨进程重开数据库和会话 / 记忆持久化。
- 外键保护、业务 / 状态匹配、金额与日期校验。
- CSV / Excel 金额和公式注入保护、失败批次全部回滚。
- 备份恢复、损坏 / 不完整备份拒绝、恢复前安全备份。
- 库存入出损耗、自动快照 / 备份重复执行。
- AI 白名单隐私、官方域名保护、SSE 完整 / 中断 / 空内容、认证 / 超时提示、模型列表协议。
- Qt 全模块加载、三种窗口尺寸、真实订单表单到统计、长 Markdown 回复滚动与输入框固定、聊天历史切换。

API 测试使用协议模拟响应，**不代表真实 DeepSeek 服务测试通过**。

## Windows 源码和打包人工验收（尚待执行）

1. 在全新 Windows 10 / 11 x64 环境安装 / 启动，窗口最小化、最大化、关闭和改变尺寸；核对中文字体和托盘。
2. 新增三业务产品、匿名客户和订单，验证三业务收入总额、成本、订单阶段过滤、客户统计；关闭后重开确认保留。
3. 花束采购 / 领用 / 损耗及库存；活动各销售阶段、报价文件和跟进；营销实验预算 / 指标 / 结果；内容计划和照片预览；复盘及记忆保存。
4. 导出 CSV / XLSX 模板及数据，在独立测试库导回；试导错行并确认无部分写入。
5. 手工备份、修改数据、恢复并确认恢复前副本；同时备份 `assets` 目录。
6. 用有效 DeepSeek Key 获取模型，发送一轮有真实测试订单的提问，检查预览只包含必要信息；观察中文 SSE / 表格 / 代码块、停止、断网 / 无效 Key、历史会话重开。
7. 选择将回复保存为草稿 / 记忆 / 待确认任务，取消时不得写入；AI 不得自动修改订单、目标或对外发送消息。
8. 验证 Windows Credential Manager 条目，确认配置 / 数据库 / 日志没有 Key；测试退出重开后的 Key 可用。
9. 打包目录整体复制到无 Python 的 Windows 机器；启动 EXE、创建快捷方式、开机启动开关、关闭到托盘。升级替换程序目录后旧数据仍保留。
10. 检查 `%LOCALAPPDATA%\ZaowuGrowthManager` 的权限、备份和照片迁移；退出程序后没有遗留工作线程。

只有上述 Windows 与真实 API 项有实际执行记录后，才能宣布 Windows 发行版和真实 AI 接入验收通过。
