# 造物手作 AI 经营管理系统

Windows 桌面经营工作台，Python 3.12 + PySide6 + SQLite。独立应用、独立数据目录，不修改其他 AI 工作台。

## 当前交付状态

本项目是可运行、可录入和持久化的首版源代码，包含 Windows 构建流程。当前开发环境为 Linux，**没有生成或验证 Windows EXE**；真实 DeepSeek 调用需要用户配置 API Key，云端还需生效的网络许可。模型列表来自服务，未预置模型名。照片支持本地导入、预览和文字描述，**未实现图像识别**。

## Windows 启动

安装 Python 3.12 x64，然后在本目录运行 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup-windows.ps1
.\start-windows.bat
```

也可直接执行 `.venv\Scripts\python.exe launch.py`，便于查看错误输出。`ExecutionPolicy Bypass` 只用于该次运行本项目脚本，不会修改系统全局执行策略。

开发环境（macOS / Linux 也可运行业务和测试）：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python launch.py
.venv/bin/python -m pytest -q
```

无显示器环境测试：`QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q`。Linux 如需真实窗口，需要系统显示服务及 Qt 所需的桌面运行库。

## 首次使用

1. 在三项业务的“项目 / 产品”录入名称、售价和材料成本；没有预填示例订单或金额。可以编辑、上架 / 下架；已被订单引用的产品不能删除。
2. 在“客户经营助手”录入匿名编号（如 C0001）、业务、来源与推广许可。无需输入姓名、电话和微信。首次和最近消费、累计次数金额由订单自动计算。
3. 在业务“订单”填写经营归属日、产品、数量、客户、获客来源与最终下单渠道。可按产品单价填充整单收入 / 材料成本，实际成交后核对金额。记录直接人工、交通等成本。订单售价及成本是交易快照，后续产品调价不改历史订单。
4. 花束管理交付日期、自提 / 配送、节日标签、订单阶段；库存通过采购、制作领用、损耗、盘盈流水维护。订单不自动扣库存，避免误判材料组成。负库存会提示核对。
5. 活动订单兼作销售线索，记录销售漏斗阶段、预计报价、实际收入、人数、地点、执行与跟进。可导出 Markdown 报价单；客户备注保留本地。
6. “营销策略制定”录入目标、实验假设、预算、成功指标和曝光→访问→咨询→订单结果；任务状态从待确认到完成，效果记入结果。
7. “内容创作助手”管理内容计划、平台、脚本与已发布状态，按计划发布日期排序 / 搜索。照片导入后编辑描述。第一版不自动发布内容。
8. “经营复盘”保存每日 / 每周 / 每月结论，录入固定费用；自动快照保存上个完整周和月的统计。任务追踪建议执行；长期结论可另存为经营记忆。

## DeepSeek 配置与使用

系统设置输入官方 HTTPS 地址（默认 `https://api.deepseek.com`，也接受 `/v1`）、Key，点击“测试连接并获取模型”，从返回列表选择并保存模型。测试模型发现不消耗聊天生成，但真实服务计费及权限以 DeepSeek 为准。

Key 不写入 SQLite 或源代码。Windows 默认使用 Credential Manager；安全凭据库不可用时可仅保留本次运行内存，或在启动进程前设置 `ZAOWU_DEEPSEEK_API_KEY`。不要把 Key 提交到 Git。设置页留空保留已有 Key；删除持久化 Key 可在 Windows“凭据管理器”中删除 `ZaowuGrowthManager.DeepSeek` 条目。

右侧聊天按当前模块构造白名单上下文：经营汇总、等长上期比较、产品价格成本、相关业务资料和已明确授权的长期记忆。客户模块还可发送最多 100 名客户的系统生成匿名编号、分类、推广许可和消费统计，AI 返回的编号可在客户列表“消费统计”列对应查找。**每次发送前均展示全部请求文本，包括会话历史**，可取消。手写客户编号、偏好、个人沟通、原始订单、照片文件不会自动上传；请核查手写营销文本和记忆中是否夹带隐私。

AI 回复支持 Markdown、代码、表格、流式显示；聊天历史独立保存，可新建、切换、重命名、删除。长回复单独滚动，输入框固定。可以保存回复为内容 / 复盘草稿或经营记忆，也可将建议转为待确认任务；都会先打开可编辑表单，由使用者点击保存。AI 本身没有执行 SQL、发送消息、发布或广告投放的通道。

发生超时、认证错误、余额不足、限流或流中断会显示明确提示。部分回复会保留并标记未完成，不作为后续完整上下文。重要结论存入长期记忆后可新开会话；过长历史不会被偷偷截断。

API 协议：OpenAI 兼容 `GET /models`、`POST /chat/completions`，SSE `data:` / `[DONE]`。官方参考入口：<https://api-docs.deepseek.com/>。当前云网络阻止文档站，**最新官方文档和真实账户兼容性尚未核验**，不能把本地模拟协议测试视为真实接入通过。官方 GitHub 仓库确认其提供 OpenAI 兼容 API：<https://github.com/deepseek-ai/DeepSeek-V3#5-chat-website--api-platform>。

## 经营统计口径

- 仅已付款、制作中、已完成、成交、活动执行、完成结算阶段计入营业额；未成交及已取消订单不计。日期是经营归属日，不是多笔收款流水。取消订单的退款 / 留存定金需人工按实际核对，当前不提供多次收款、部分退款及会计总账。
- 贡献毛利 = 实际收入 − 材料成本 − 直接人工 − 其他直接成本。
- 总览展示扣除**已录固定费用**后的结余，不将其冒称最终净利润。分类业务不分摊门店固定费用。采购金额不再重复计入订单材料成本。
- 客单价 = 成交收入 / 成交订单；客户数按已关联匿名客户去重；新客户按全库首次成交日判断；未关联订单单独提示，不推算人数。
- 产品销售、业务占比、日趋势、渠道 / 来源、营销获客成本、活动当前阶段漏斗都来自数据库。活动成交比例按已录非取消线索计算，不假装完整平台转化率。
- 无订单展示“暂无数据”或真实汇总零值，不生成虚构趋势。页面支持日报、周报、月报、年报、自选区间、等长上期对比。

## 导入、导出与备份

列表提供 Excel / CSV 模板、导入和导出。模板保留英文数据库字段名，金额以**元**录入，日期 `YYYY-MM-DD`，布尔用 0 / 1，选择项使用 UI 的中文原值。客户及产品关联字段使用本库数字编号（列表第一列）。建议先导产品、客户，再导订单。导入是**新增**而不是更新；文件 `id` 不用于覆盖原记录，重复导入订单会重复新增。任一行失败全部回滚，导入前自动备份。

数据库：`%LOCALAPPDATA%\ZaowuGrowthManager\zaowu.sqlite3`；非 Windows 为 `~/.local/share/ZaowuGrowthManager/`。可用 `ZAOWU_DATA_DIR` 指定隔离的测试目录。数据库升级不放在安装目录。

每日自动备份到 `backups/`，应用启动及每小时检查；保留最近 30 个自动目录内备份。手动备份可选择外部位置。恢复校验版本、表结构、关联完整性并创建恢复前备份。**SQLite 备份不包含 `assets/` 照片或 OS 凭据**；完整搬迁请在关闭程序后复制整个数据目录，重新配置 Key。用户数据目前不加密，建议 Windows 账户保护 / BitLocker。

## Windows 打包和桌面快捷方式

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-windows.ps1
```

产物：`dist\ZaowuGrowthManager\ZaowuGrowthManager.exe`。需分发整个文件夹，不能只拷贝 EXE。在产物文件夹运行 `create-desktop-shortcut.ps1` 可创建桌面快捷方式。系统设置支持可选开机启动，默认关闭；可选关闭到托盘，默认关闭；托盘运行时数据库、自动备份及网络请求不依赖主界面可见。

仓库提供 `.github/workflows/windows-build.yml`，可在 GitHub Actions 手动触发 Windows 测试打包并下载 Artifact。本次未推送、触发或验证此远程工作流。PyInstaller 不支持在 Linux 直接生成已验证的 Windows EXE；发布前必须在 Windows 完成 [验收清单](docs/ACCEPTANCE.md)。

架构、数据库和功能范围见 [技术说明](docs/ARCHITECTURE.md)。
